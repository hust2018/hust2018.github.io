# 个人简历网站

终端 / 科技风的单页简历，双语 + 深浅色 + 三种风格切换。

## 运行

直接用浏览器打开 `index.html` 即可（无需任何构建工具 / 服务器）。
要上线，把整个文件夹上传到任意静态托管（GitHub Pages / Vercel / Netlify / 自己的服务器）。

## 文件说明

| 文件 | 作用 | 你需要改的 |
|------|------|-----------|
| `data.jsx` | **所有简历内容**（姓名、经历、项目、技能、联系方式） | ✅ 主要改这里 |
| `index.html` | 页面骨架、字体、标题 | 改 `<title>` |
| `styles.css` | 全部样式与动效 | 想调外观时改 |
| `components.jsx` | 各区块的渲染逻辑 | 一般不用动 |
| `app.jsx` | 主程序、Tweaks 面板、默认风格 | 改默认配色/风格 |
| `tweaks-panel.jsx` / `image-slot.js` | 工具组件 | 不用动 |

## 改内容

打开 `data.jsx`，里面每条都有 `{ zh: "中文", en: "English" }` 的双语结构，直接替换占位文字即可。
顶部的 `meta`（user/host/cwd）控制终端提示符里的 `you@portfolio:~/resume` 那串字。

## 换头像

打开网站后，把图片拖进 Hero 区右侧的方框，会自动保存在浏览器里。
（若要让头像随文件分发，可在 `data.jsx` 里改成 `<img>` 引用本地图片——需要我帮忙可以说。）

## 导出 PDF

打开网站点右上角 `打印`，或浏览器 Cmd/Ctrl+P。已做打印优化：自动去掉特效、展开所有经历、转为黑白排版。

## 风格切换

右下角 Tweaks 面板：Terminal / IDE Dark / Paper 三种主题、accent 配色、扫描线、光标闪烁等。
右上角可切 中/英、深/浅色。
